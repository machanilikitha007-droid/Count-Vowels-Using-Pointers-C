# Count Vowels Using Pointers in C

## Project Description

A simple C program that uses a pointer to count the number of vowels in a given string.

## Features

- Accept a string
- Access characters using a pointer
- Count vowels
- Display the result

## Technologies Used

- C
- Pointers
- Strings
- Loops

## How to Run

Compile and run the `count_vowels_pointer.c` file using a C compiler.
